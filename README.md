README - Granitka71 Order Management System 
О проекте
Веб-приложение для управления заказами на изготовление памятников. Автоматизация полного цикла работы с заказами с системой безопасности.

Технологии
Backend: C# ASP.NET Core Web API 
Frontend: HTML, CSS, JavaScript 
Database: PostgreSQL 
Auth: JWT Tokens 
Роли пользователей
Администратор - полный доступ, управление пользователями
Менеджер - работа только со своими заказами
 Основные функции
 Создание и редактирование заказов
 Поиск и фильтрация заказов �
 Загрузка фотографий 
 Печать заказов 
 Мягкое удаление и архив 
Безопасность
JWT аутентификация
Ролевая модель доступа
Защита от SQL-инъекций
HTTPS на продакшене
Архитектура
RESTful API
Клиент-серверная архитектура
